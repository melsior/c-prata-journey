### Шаг 1: Инициализация репозитория и GitHub

Откройте терминал в Arch Linux и настройте проект:

```bash
# 1. Создаем папку и заходим в нее
mkdir -p ~/c_prata
cd ~/c_prata

# 2. Инициализируем git
git init -b main

# 3. Добавляем правильный .gitignore (чтобы не коммитить скомпилированные бинарники!)
cat << 'EOF' > .gitignore
# Исполняемые файлы без расширений
*
!*/
!*.c
!*.h
!*.md
!Makefile
!.gitignore
!.clang-format

# Отладочные дампы и мусор
*.o
*.out
*.dSYM/
.cache/
EOF
```

#### Привязка к GitHub:
Если у вас установлен консольный клиент GitHub (`sudo pacman -S github-cli`), можно создать и привязать репозиторий одной командой:
```bash
gh repo create c-prata-journey --public --source=. --remote=origin --push
```
*(Или создайте пустой репозиторий `c-prata-journey` на сайте github.com и привяжите стандартно через `git remote add origin git@github.com:...`)*.

### Шаг 3: Автоматизация коммита упражнения

Чтобы не тратить мотивацию на рутину вроде `git add ... && git commit ... && git push`, добавим полезную команду прямо в наш корневой `Makefile`.

Создайте или дополните файл `~/c_prata/Makefile`:

```makefile
CC = gcc
CFLAGS = -Wall -Wextra -Wpedantic -std=c11 -g

# Сборка любого файла: `make chapter02/ex01`
%: %.c
	$(CC) $(CFLAGS) $< -o $@

# Команда автоматического коммита и отправки
# Использование: make done FILE=chapter02/ex01.c
done:
	@if [ -z "$(FILE)" ]; then echo "Ошибка: укажите файл. Пример: make done FILE=chapter02/ex01.c"; exit 1; fi
	git add $(FILE) README.md
	git commit -m "Complete: $$(basename $(FILE) .c)"
	git push origin main
	@echo "🚀 Упражнение отправлено в GitHub! Квадрат позеленел."

clean:
	find . -type f -executable ! -name "*.*" -delete
```
